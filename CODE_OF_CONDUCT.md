# Code of conduct

This project welcomes technical contributions in English or 简体中文. Treat
contributors with respect, including people with different backgrounds,
experience levels and communication styles.

## Expectations

- Discuss code, evidence and tradeoffs; disagree constructively.
- Do not harass, threaten, discriminate, impersonate others or publish personal
  information without consent.
- Do not post credentials, subscriber identifiers or private communications.
- Respect copyright, attribution and another contributor's existing work.
- Accept moderation and corrective feedback without retaliation.

These expectations apply to repository issues, pull requests, reviews and other
project-managed spaces. The maintainer may remove inappropriate content or
restrict participation proportionately to protect the community.

## Reporting

For harassment, personal-data disclosure or other abuse, use GitHub's **Report
content / Report abuse** tools; do not create a public thread containing the
victim's private information. Security vulnerabilities use the separate
[security policy](SECURITY.md). General non-sensitive process concerns can be
raised in an issue without naming or exposing a private reporter.
